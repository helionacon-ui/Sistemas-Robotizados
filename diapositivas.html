01 · Robot

Cadena cinemática

  • Un robot es una cadena de eslabones unidos por articulaciones.
  • Articulación de rotación (R): gira un ángulo θ. Articulación prismática (P): se desliza una distancia d.
  • El extremo es la herramienta. Su posición y orientación dependen de todas las articulaciones.

02 · Matemáticas

Matriz de transformación homogénea

T = [ R p ; 0 1 ] (R: 3×3 rotación, p: 3×1 posición)

Paso a paso para componer dos movimientos:

  1. Escribe cada movimiento como una matriz 4×4.
  2. Multiplica en el orden en que ocurren, de izquierda a derecha según el sistema de referencia.
  3. La columna de posición del producto final es la posición del extremo.

03 · Denavit-Hartenberg

Cómo rellenar la tabla DH

  1. Numera los eslabones de la base (0) al extremo (n).
  2. Coloca el eje z de cada articulación: el eje de giro o de deslizamiento.
  3. Coloca x como la perpendicular común entre zi−1 y zi.
  4. Para cada eslabón, anota θ, d, a y α, y multiplica Aᵢ = Rz(θ) · Tz(d) · Tx(a) · Rx(α).

04 · Cinemática directa

Robot plano 2R: de ángulos a posición

x = l₁ cos θ₁ + l₂ cos(θ₁ + θ₂) y = l₁ sen θ₁ + l₂ sen(θ₁ + θ₂)
  1. Calcula la posición del codo: (l₁ cos θ₁, l₁ sen θ₁).
  2. Suma el segundo eslabón, que gira un ángulo total θ₁ + θ₂.
  3. Resultado: una única posición para unos ángulos dados.

05 · Cinemática inversa

De posición a ángulos (2R), paso a paso

  1. Calcula r² = x² + y².
  2. cos θ₂ = (r² − l₁² − l₂²) / (2 l₁ l₂). Si |cos θ₂| > 1, el punto está fuera de alcance.
  3. θ₂ = ± arccos(cos θ₂). El signo elige el codo: θ₂ > 0 codo arriba, θ₂ < 0 codo abajo (convención de esta guía).
  4. θ₁ = atan2(y, x) − atan2(l₂ sen θ₂, l₁ + l₂ cos θ₂).

Prueba estos pasos en el diagrama interactivo de la sección siguiente.

06 · Velocidades

Jacobiana: de velocidades articulares a velocidad del extremo

v = J(q) · q̇
  1. Deriva x e y respecto a θ₁ y θ₂. Cada derivada es un elemento de J.
  2. Para el 2R: J = [ −l₁ sen θ₁ − l₂ sen θ₁₂ , −l₂ sen θ₁₂ ; l₁ cos θ₁ + l₂ cos θ₁₂ , l₂ cos θ₁₂ ], con θ₁₂ = θ₁ + θ₂.
  3. Multiplica J por q̇ para obtener v. Para invertir el problema, usa J⁻¹ si existe.

07 · Singularidades

Cuándo falla la Jacobiana

  1. Una configuración es singular si det J = 0.
  2. Para el 2R plano: det J = l₁ l₂ sen θ₂.
  3. Singular cuando θ₂ = 0° o θ₂ = 180°: el brazo está estirado o doblado del todo, y se pierde una dirección de movimiento.

08 · Orientación

Cuaterniones para girar un vector

q = (cos θ/2, sen θ/2 · n) v′ = q · (0, v) · q*
  1. Toma el eje unitario n y el ángulo θ.
  2. Construye q = (w, x, y, z) con w = cos(θ/2) y (x, y, z) = sen(θ/2) · n.
  3. Conjugado: q* = (w, −x, −y, −z).
  4. Calcula q · (0, v) · q* y toma la parte vectorial: es el vector girado.

09 · Trayectorias

Spline cúbico entre dos puntos, paso a paso

q(t) = a + b·t + c·t² + d·t³ con t desde el inicio del tramo, T = duración
  1. Impón las cuatro condiciones: q(0) = q₀, q(T) = q_T, q̇(0) = v₀, q̇(T) = v_T.
  2. a = q₀ y b = v₀.
  3. Llama Δ = q_T − q₀. Entonces c = 3Δ/T² − (2v₀ + v_T)/T y d = −2Δ/T³ + (v₀ + v_T)/T².
  4. Si hay que imponer una velocidad máxima en un instante, usa q̈ = 0 ahí y despeja.

10 · Dinámica

Modelo dinámico y par estático

  1. Lagrange: escribe la energía cinética K y la potencial U, y calcula L = K − U.
  2. Obtén τ = M(q) q̈ + C(q, q̇) q̇ + G(q) derivando L.
  3. Par estático (robot parado): τ = Jᵀ F, con F la fuerza en el extremo.

11 · Examen

Plan para resolver un ejercicio de examen

  1. Lee el enunciado dos veces. Anota los datos y las incógnitas.
  2. Dibuja la configuración y etiqueta los ángulos.
  3. Elige la herramienta: DH, cinemática inversa, Jacobiana, spline o cuaterniones.
  4. Calcula sin redondear hasta el final. Comprueba la unidad y el signo del resultado.
  5. Compara con la solución de referencia y anota los errores en tu autoevaluación.

Ejercicio A · Cinemática inversa de un 2R plano (dos soluciones)

Enunciado. Robot plano de dos eslabones con l₁ = l₂ = 1. Calcula las articulaciones para llevar el extremo al punto (1, 1) y al punto (0,5 ; 0,5). Indica las dos soluciones.

Antes de empezar: qué piden (θ₁ y θ₂) y qué teoría usas (ley de cosenos para θ₂, atan2 para θ₁; las dos soluciones son codo arriba y codo abajo).
Paso 1 · Calcular cos θ₂

cos θ₂ = (x² + y² − l₁² − l₂²) / (2 l₁ l₂). Para (1, 1): cos θ₂ = (1 + 1 − 1 − 1)/2 = 0, así que θ₂ = ±90°.

Paso 2 · Calcular θ₁ para cada θ₂

θ₁ = atan2(y, x) − atan2(l₂ sin θ₂, l₁ + l₂ cos θ₂).

Para θ₂ = +90°: atan2(1, 1) = 45° y atan2(1, 1 + 0) = 45°, así que θ₁ = 45° − 45° = 0°.

Para θ₂ = −90°: atan2(−1, 1 + 0) = −45°, así que θ₁ = 45° − (−45°) = 90°.

Ojo: el signo es fácil de equivocar. Comprueba siempre el resultado sustituyendo en la cinemática directa, como en el paso 3.

Paso 3 · Comprobar sustituyendo

Codo arriba: θ₁ = 0°, θ₂ = 90° → x = cos 0° + cos 90° = 1, y = sin 0° + sin 90° = 1. ✔

Codo abajo: θ₁ = 90°, θ₂ = −90° → x = cos 90° + cos 0° = 1, y = sin 90° + sin 0° = 1. ✔

Paso 4 · Punto (0,5 ; 0,5)

cos θ₂ = (0,25 + 0,25 − 2)/2 = −0,75, así que θ₂ ≈ ±138,59°. Con el cálculo completo: codo arriba θ₁ ≈ −24,30°, θ₂ ≈ 138,59°; codo abajo θ₁ ≈ 114,30°, θ₂ ≈ −138,59°. Ambas llevan el extremo a (0,5 ; 0,5).

Resultado final: (1, 1) → codo arriba (0°, 90°) o codo abajo (90°, −90°). (0,5 ; 0,5) → codo arriba (−24,30°, 138,59°) o codo abajo (114,30°, −138,59°).
Ejercicio B · Jacobiana y singularidad del 2R plano

Enunciado. Halla la Jacobiana del 2R plano con l₁ = l₂ = 1 y encuentra en qué configuraciones es singular.

Antes de empezar: derivar x e y respecto a θ₁ y θ₂ y ordenar los resultados en una matriz 2 × 2. Una configuración es singular cuando det J = 0.
Paso 1 · Derivar

∂x/∂θ₁ = −l₁ sin θ₁ − l₂ sin(θ₁+θ₂), ∂x/∂θ₂ = −l₂ sin(θ₁+θ₂), ∂y/∂θ₁ = l₁ cos θ₁ + l₂ cos(θ₁+θ₂), ∂y/∂θ₂ = l₂ cos(θ₁+θ₂).

Paso 2 · Determinante

Al calcular el determinante, sale det J = l₁ l₂ sin θ₂. Comprobado con código para θ₁ = 0,3 rad y θ₂ = 0,8 rad.

Resultado final: J singular cuando sin θ₂ = 0, es decir, θ₂ = 0 o θ₂ = π.
Ejercicio C · Spline cúbico con velocidad nula en los extremos

Enunciado. Una articulación pasa de θ = 0 a θ = π/2 en el intervalo t ∈ [0, 1] s, con velocidad cero al inicio y al final. Halla el polinomio cúbico.

Antes de empezar: son 4 condiciones y 4 incógnitas.
Paso 1 · Escribir las condiciones

θ(0) = a₀ = 0. θ̇(0) = a₁ = 0. θ(1) = a₂ + a₃ = π/2. θ̇(1) = 2a₂ + 3a₃ = 0.

Paso 2 · Resolver

De la última ecuación, a₂ = −3a₃/2. Sustituyendo: −3a₃/2 + a₃ = π/2, luego a₃ = −π y a₂ = 3π/2.

Resultado final: θ(t) = (3π/2) t² − π t³. Comprobado: θ(1) = π/2 y θ̇(0) = θ̇(1) = 0.

Ejercicio E · Jacobiana y velocidades de un robot de 2 articulaciones (parcial de 2021)

Enunciado. La posición del extremo es x = cos θ₁ (1 + cos θ₂), y = sen θ₁ (1 + cos θ₂), z = −sen θ₂. La coordenada z es siempre positiva. Calcula: a) la Jacobiana de velocidades lineales; b) las velocidades articulares cuando x = y = 1 m, ẋ = 2 m/s y ż = 1 m/s, sin usar la pseudoinversa; c) ẏ en ese caso.

Antes de empezar: primero hay que encontrar la configuración (θ₁, θ₂) a partir de la posición. Después se deriva para obtener J, y con ẋ y ż se resuelve un sistema 2 × 2. La velocidad ẏ se obtiene al final, sustituyendo.
Paso 1 · Encontrar la configuración

Si x = y = 1, entonces x² + y² = (1 + cos θ₂)² · (cos²θ₁ + sen²θ₁) = 2, así que 1 + cos θ₂ = √2 y cos θ₂ = √2 − 1 ≈ 0,4142. Como z = −sen θ₂ > 0, sen θ₂ < 0: sen θ₂ = −√(1 − 0,4142²) ≈ −0,9102, luego θ₂ ≈ −65,53°. Además cos θ₁ = sen θ₁ = 1/√2 y θ₁ = 45°. Comprobación: z = 0,9102 > 0. ✔

Paso 2 · Jacobiana

Derivando: ∂x/∂θ₁ = −sen θ₁ (1 + cos θ₂), ∂x/∂θ₂ = −cos θ₁ sen θ₂; ∂y/∂θ₁ = cos θ₁ (1 + cos θ₂), ∂y/∂θ₂ = −sen θ₁ sen θ₂; ∂z/∂θ₁ = 0, ∂z/∂θ₂ = −cos θ₂.

Evaluada en el punto: J = [[−1 ; 0,6436], [1 ; 0,6436], [0 ; −0,4142]].

Paso 3 · Resolver ẋ y ż

Con ż = −0,4142 θ̇₂ = 1 sale θ̇₂ = −2,4142 rad/s. Con ẋ = −θ̇₁ + 0,6436 θ̇₂ = 2 sale θ̇₁ = −3,5538 rad/s.

La matriz 2 × 2 de las filas x y z tiene determinante 0,4142 ≠ 0, así que la solución es única.

Paso 4 · Calcular ẏ

ẏ = θ̇₁ + 0,6436 θ̇₂ = −3,5538 + 0,6436 · (−2,4142) = −5,1075 m/s.

Comprobación: sustituyendo en la fila x, −(−3,5538) + 0,6436 · (−2,4142) = 2,0000. ✔

Resultado final: θ̇₁ ≈ −3,554 rad/s, θ̇₂ ≈ −2,414 rad/s, ẏ ≈ −5,11 m/s.
Ojo: el enunciado prohíbe la pseudoinversa. Con dos ecuaciones y dos incógnitas no hace falta: basta resolver el sistema directamente.
Ejercicio F · Distancia a la segunda articulación en un 2R con interpoladores lineales (junio de 2019)

Enunciado. Robot plano de 2 eslabones de 1 m. La articulación 1 gira 90° en 3 s y la 2 gira 45° en 2 s, con interpolador lineal. Cuando el segundo eslabón pasa por el punto (1,2 ; 0,5), calcula la distancia a entre ese punto y la segunda articulación.

Antes de empezar: la figura no está en el texto. Supón que la configuración inicial es el robot estirado sobre el eje x (θ₁ = θ₂ = 0). Lo que piden es a = |P − p₂|, donde p₂ es la posición de la articulación 2. El punto P está sobre el segundo eslabón cuando P − p₂ es paralelo a la dirección del eslabón.
Paso 1 · Leyes horarias

θ₁(t) = (π/2) · t/3 para 0 ≤ t ≤ 3 s, y θ₂(t) = (π/4) · t/2 para 0 ≤ t ≤ 2 s (después se queda en 45°).

Paso 2 · Posición de la articulación 2 y dirección del segundo eslabón

p₂ = (cos θ₁, sen θ₁). La dirección del segundo eslabón es u = (cos(θ₁ + θ₂), sen(θ₁ + θ₂)).

Paso 3 · Condición de alineación

Se busca t tal que el producto vectorial (P − p₂) × u sea cero, y que la proyección (P − p₂) · u esté entre 0 y 1 m. Como el movimiento es continuo, el cruce se localiza barriendo t en el intervalo.

Paso 4 · Resolver y calcular a

Hay un único cruce en 0 ≤ t ≤ 3 s, en t ≈ 0,641 s. Allí θ₁ ≈ 19,24° y θ₂ ≈ 14,43°, p₂ ≈ (0,944 ; 0,330) y P − p₂ ≈ (0,256 ; 0,170). La proyección sobre u es 0,307 m (positiva y menor que 1, así que P está sobre el eslabón).

Entonces a = |P − p₂| ≈ 0,307 m.

Resultado final: a ≈ 0,307 m, cuando t ≈ 0,641 s.
Ejercicio G · Instantes en que el extremo pasa por dos puntos de una recta (febrero y junio de 2016)

Enunciado. El extremo de un robot 2R con eslabones de 1 m sigue la recta que va de B (0,4 ; 0,4) a C (1,4 ; 1,4), es decir, y = x. El movimiento dura 1 s. Calcula los instantes en que pasa por A₁ (a 0,5 m de B) y por A₂ (a 0,3 m de C), y los ángulos θ₁ y θ₂ en esos instantes, con 0 ≤ θ₂ ≤ π. Hay dos variantes: en junio, la coordenada x(t) sigue un interpolador lineal; en febrero, un spline cúbico que empieza y acaba con velocidad cero.

Antes de empezar: como la recta es y = x, la distancia sobre la recta se traduce en la coordenada x. Para A₁, x = 0,4 + 0,5/√2 ≈ 0,7536. Para A₂, x = 1,4 − 0,3/√2 ≈ 1,1879. La variante cambia solo los instantes, no los ángulos.
Paso 1 · Coordenadas de A₁ y A₂

A₁ = (0,7536 ; 0,7536) y A₂ = (1,1879 ; 1,1879).

Paso 2 · Instantes

Lineal: x(t) = 0,4 + t, así que t₁ = 0,354 s y t₂ = 0,788 s.

Spline: x(t) = 0,4 + (3t² − 2t³). Resolviendo numéricamente, t₁ ≈ 0,401 s y t₂ ≈ 0,703 s. Comprobación: 3 · 0,401² − 2 · 0,401³ = 0,354, que coincide con 0,7536 − 0,4.

Paso 3 · θ₂ por la ley de cosenos

Con y = x: cos θ₂ = (x² + y² − 2)/2 = x² − 1. Para A₁: cos θ₂ ≈ −0,4319, θ₂ ≈ 115,61°. Para A₂: cos θ₂ ≈ 0,4116, θ₂ ≈ 65,73°. Los dos son positivos, así que cumplen 0 ≤ θ₂ ≤ π y la solución es la de codo arriba.

Paso 4 · θ₁

θ₁ = atan2(y, x) − atan2(sen θ₂, 1 + cos θ₂). Para A₁: 45° − 57,80° = −12,80°. Para A₂: 45° − 32,86° = 12,14°.

Comprobación: sustituyendo en la cinemática directa se recupera (0,7536 ; 0,7536) y (1,1879 ; 1,1879). ✔

Resultado final:
A₁: t = 0,354 s (lineal) o 0,401 s (spline); θ₁ = −12,80°, θ₂ = 115,61°.
A₂: t = 0,788 s (lineal) o 0,703 s (spline); θ₁ = 12,14°, θ₂ = 65,73°.
Ejercicio H · Velocidad del extremo en los puntos de paso A, B y C (junio de 2024)

Enunciado. El extremo de un robot de 2 eslabones de 1 m sigue la trayectoria A (0,5 ; 1) → B (1 ; 1) → C (1,4 ; 0,7). Las articulaciones usan un interpolador lineal, 1 s por tramo, y el robot va en codo abajo. Comprueba si en algún punto de paso la velocidad del extremo supera 0,6 m/s.

Antes de empezar: con interpolador lineal en articulaciones, q̇ es constante dentro de cada tramo y cambia de golpe en cada punto de paso. Por eso en cada punto hay dos velocidades, la del final del tramo anterior y la del inicio del siguiente. Hay que comprobar las dos.
Paso 1 · Cinemática inversa en codo abajo

A: θ = (119,45° ; −112,02°). B: θ = (90,00° ; −90,00°). C: θ = (65,06° ; −77,00°). Comprobación: la cinemática directa devuelve los tres puntos.

Paso 2 · Velocidades articulares en cada tramo

Tramo AB (1 s): q̇ = (−0,514 ; 0,384) rad/s. Tramo BC (1 s): q̇ = (−0,435 ; 0,227) rad/s.

Paso 3 · Velocidad del extremo v = J(θ) q̇

Con J = [[−sen θ₁ − sen θ₁₂ , −sen θ₁₂], [cos θ₁ + cos θ₁₂ , cos θ₁₂]]:

En A (tramo AB): |v| ≈ 0,481 m/s. En B, final de AB: |v| ≈ 0,530 m/s. En B, inicio de BC: |v| ≈ 0,483 m/s. En C, final de BC: |v| ≈ 0,523 m/s.

Paso 4 · Máximo dentro de cada tramo

Barriendo el tramo, el máximo se alcanza al final: 0,530 m/s en AB y 0,523 m/s en BC. No hay ningún punto por encima de 0,6 m/s.

Resultado final: ningún punto de paso supera 0,6 m/s. La mayor velocidad es 0,53 m/s, en B.
Ojo: si el examen define el codo de otra forma, los valores de θ cambian (y también la velocidad). Comprueba la convención antes de dar el resultado.
Ejercicio I · Interpolador articular que pasa por un punto (julio de 2021)

Enunciado. Robot 2R con eslabones de 1 m. El extremo parte de A (0,7 ; 1,1), pasa por B (1,5 ; 0,2) y termina en C en 1 s, en codo abajo. Las dos articulaciones se mueven con interpoladores lineales, en un único tramo. Al acabar, θ₁ = −50°. Calcula el instante en que pasa por B, las ecuaciones de θ₁(t) y θ₂(t) y las coordenadas de C.

Antes de empezar: las incógnitas son el instante s en que se pasa por B y el valor final θ₂C (que es lo que define C). Son dos incógnitas y dos ecuaciones, las coordenadas de B. Hay que resolverlas juntas.
Paso 1 · Configuración inicial

Con codo abajo, θ_A = (106,84° ; −98,63°). Comprobación: la cinemática directa devuelve A = (0,7 ; 1,1).

Paso 2 · Interpolador lineal

q(s) = θ_A + s (θ_C − θ_A), con 0 ≤ s ≤ 1 y t = s. Como θ₁C = −50°, la primera articulación es θ₁(t) = 106,84° − 156,84° · t.

Paso 3 · Pasar por B

Hay que cumplir cinemática directa(q(s)) = (1,5 ; 0,2). Con dos ecuaciones y dos incógnitas (s y θ₂C), se resuelve numéricamente (Newton). Solución: s ≈ 0,3725 y θ₂C ≈ −53,08°.

La otra solución que aparece tiene θ₂C ≈ +103°, es decir, codo arriba al final. Se descarta porque el enunciado pide codo abajo.

Paso 4 · Ecuaciones y C

θ₂(t) = −98,63° + 45,55° · t, que se mantiene negativo en todo el movimiento (codo abajo).

En radianes: θ₁(t) = 1,865 − 2,737 t y θ₂(t) = −1,721 + 0,795 t. Comprobación: θ₂(0,3725) ≈ −81,65°, y la cinemática directa da (1,499 ; 0,207) ≈ B. ✔

C = cinemática directa(−50°, −53,08°) = (0,417 ; −1,740) m.

Resultado final: el extremo pasa por B en t ≈ 0,372 s. θ₁(t) = 1,865 − 2,737 t (rad), θ₂(t) = −1,721 + 0,795 t (rad). C ≈ (0,417 ; −1,740) m.
Ejercicio J · Spline cúbico seguido de interpolador lineal en una articulación (febrero de 2020)

Enunciado. Una articulación gira de 0 a 1 rad en 3 s. Entre 0 y 2 s se ajusta un spline cúbico q₁(t), y entre 2 y 3 s un interpolador lineal q₂(t). En t = 2 s hay continuidad de posición y de velocidad. La velocidad inicial es cero y la velocidad máxima que alcanza es 5 rad/s. Elige la solución que cumple q(2) > 1 rad.

Antes de empezar: llama a = q(2) y v = q̇(2). El interpolador lineal vale q₂(t) = a + v (t − 2), y debe cumplir q₂(3) = 1. El spline con q(0) = 0 y q̇(0) = 0 es q(t) = b t² + c t³. Hay que imponer tres condiciones: el valor de velocidad en t = 2, la condición de q₂(3) = 1 y que la velocidad máxima del spline sea 5 rad/s.
Paso 1 · Condiciones de continuidad

q(2) = 4b + 8c = a. q̇(t) = 2bt + 3ct², así que q̇(2) = 4b + 12c = v.

El lineal tiene pendiente v, y por continuidad de velocidad, q₂(3) = a + v = 1. Entonces 4b + 12c = 1 − (4b + 8c), es decir, 8b + 20c = 1, o bien b = 1/8 − 5c/2.

Paso 2 · Velocidad máxima

q̈ = 2b + 6ct = 0 da t* = −b/(3c). Sustituyendo en q̇: q̇(t*) = −b²/(3c). Imponiendo |q̇| = 5 con q̇ máxima en [0, 2]: −b²/(3c) = 5, es decir b² = −15c.

Sustituyendo b = 1/8 − 5c/2: 400c² + 920c + 1 = 0. Sus raíces son c = −(23 + 4√33)/20 ≈ −2,2989 y c ≈ −0,0011.

Paso 3 · Elegir la raíz

Con c ≈ −0,0011, b ≈ 0,1277 y t* ≈ 39 s, fuera de [0, 2]. Esa raíz no da un máximo dentro del intervalo y se descarta.

Con c = −(23 + 4√33)/20: b = (6 + √33)/2 ≈ 5,8723 y t* ≈ 0,851 s, dentro de [0, 2]. Además a = q(2) = 2,8 + 0,4√33 ≈ 5,098 > 1, que es la condición del enunciado.

Paso 4 · Ecuaciones y comprobación

q₁(t) = ((6 + √33)/2) t² − ((23 + 4√33)/20) t³ para 0 ≤ t ≤ 2 (rad).

q₂(t) = a + (1 − a)(t − 2) = (2,8 + 0,4√33) − (1,8 + 0,4√33)(t − 2) para 2 ≤ t ≤ 3 (rad), es decir, q₂(t) ≈ 5,098 − 4,098 (t − 2).

Comprobación: q₂(3) = 1 ✔; q₁(2) = q₂(2) ≈ 5,098 ✔; q̇₁(2) = −4,098 = pendiente de q₂ ✔; |q̇₁| máxima = 5,000 en t ≈ 0,851 s ✔.

Resultado final: q₁(t) ≈ 5,872 t² − 2,299 t³ (0 ≤ t ≤ 2 s) y q₂(t) ≈ 5,098 − 4,098 (t − 2) (2 ≤ t ≤ 3 s).
Ojo: la articulación sobrepasa 1 rad y vuelve a 1 rad en t = 3 s. Es lo que el enunciado pide al elegir q(2) > 1 rad; no es un error de cálculo.
Ejercicio K · Velocidad, mínimo y aceleración en un 2R con velocidades articulares constantes (junio de 2019)

Enunciado. Robot plano de 2 eslabones que se mueve en un plano horizontal durante 4 s con velocidad angular constante de 1 rad/s en ambas articulaciones. Calcula: a) el instante en que el extremo alcanza 2 m/s; b) el valor mínimo de la velocidad y el instante en que se alcanza; c) las componentes de la aceleración lineal del extremo en t = 1,823 s, respecto a la base.

Antes de empezar: supón que el robot empieza estirado sobre el eje x y que θ₁ = θ₂ = t. Con esa suposición, la velocidad al cuadrado se simplifica mucho y la respuesta del apartado a) se confirma con el propio 1,823 s del enunciado.
Paso 1 · Posición del extremo

x(t) = cos t + cos 2t, y(t) = sen t + sen 2t.

Paso 2 · Módulo de la velocidad

ẋ = −sen t − 2 sen 2t y ẏ = cos t + 2 cos 2t. Entonces |v|² = ẋ² + ẏ² = 5 + 4 cos t.

Esto sale de expandir los cuadrados y usar que sen²+cos² = 1, y que cos 2t·cos t + sen 2t·sen t = cos t.

Paso 3 · Apartado a) |v| = 2 m/s

4 = 5 + 4 cos t, así que cos t = −1/4. En [0, 4] s hay una sola solución: t = arccos(−1/4) ≈ 1,823 s. (La otra, 4,460 s, queda fuera del intervalo.)

Paso 4 · Apartado b) mínimo

|v|² = 5 + 4 cos t es mínimo cuando cos t = −1, es decir t = π ≈ 3,142 s. Entonces |v|² = 1 y |v|_min = 1 m/s.

En t = 0, la velocidad es 3 m/s (máximo).

Paso 5 · Apartado c) aceleración

Como las velocidades articulares son constantes, la aceleración es la derivada de la velocidad: a = d/dt (ẋ, ẏ).

a_x = −cos t − 4 cos 2t y a_y = −(8 cos t + 1) sen t.

En t = 1,823 s, cos t = −1/4, cos 2t = −7/8 y sen t = √15/4 ≈ 0,968. Entonces a_x = 0,25 + 3,5 = 3,750 m/s² y a_y = 0,968 m/s².

Comprobación: sustituyendo t = 1,823 s en las expresiones simbólicas se obtiene (3,751 ; 0,965) m/s², que coincide con la forma exacta dentro del redondeo.

Resultado final: a) t ≈ 1,823 s. b) |v| mínimo = 1 m/s en t ≈ 3,142 s. c) a ≈ (3,75 ; 0,968) m/s² en la base.
Ejercicio L · Spline cúbico con velocidad máxima en el punto medio (solución de referencia 4 de Trayectorias)

Enunciado. Una articulación pasa de q = 0 rad a q = 2 rad en t ∈ [0, 5] s, con un spline cúbico de una sola ecuación. La velocidad máxima debe alcanzarse a mitad del recorrido (tm = 2,5 s) y valer 1 rad/s.

Antes de empezar: con a = q₀ = 0 quedan 3 incógnitas, b, c y d. Las condiciones son q(5) = 2, q̇(2,5) = 1 y q̈(2,5) = 0.
Paso 1 · Relacionar c con d con la condición de q̈ = 0

q̈(t) = 2c + 6d·t. Hacerla cero en tm = 2,5 s da 2c + 15d = 0, luego c = −7,5 d.

Paso 2 · Relacionar b con d con la condición de velocidad

q̇(t) = b + 2c·t + 3d·t². En t = 2,5: b + 5c + 18,75d = 1. Sustituyendo c = −7,5d: b = 1 + 18,75 d.

Paso 3 · Calcular d con la condición de posición

q(5) = 5b + 25c + 125d = 2. Sustituyendo b y c: 5 + 93,75d − 187,5d + 125d = 2, es decir 5 + 31,25d = 2. Entonces d = −3 / 31,25 = −0,096.

Paso 4 · Obtener c y b

c = −7,5 · (−0,096) = 0,72. b = 1 + 18,75 · (−0,096) = −0,8.

Polinomio: q(t) = −0,8 t + 0,72 t² − 0,096 t³.

Paso 5 · Comprobar las tres condiciones

q(5) = −4 + 18 − 12 = 2 ✓. q̇(2,5) = −0,8 + 3,6 − 1,8 = 1 ✓. q̈(2,5) = 1,44 − 1,44 = 0 ✓.

Ojo: la velocidad inicial es q̇(0) = −0,8 rad/s. Por eso la articulación baja hasta q ≈ −0,242 rad hacia t ≈ 0,64 s, antes de subir. Cumple las condiciones del enunciado, pero si el robot no puede tomar valores negativos, habría que añadir una condición o cambiar el tiempo. La solución de referencia no lo comenta.
Ejercicio M · Posición y velocidad del extremo de un robot con dinámica (solución de referencia de Dinámica)

Enunciado. El robot parte del reposo. Sus actuadores siguen Γ(t) = 3t² + 2t + 20 y F(t) = 5t + 10, con paso de muestreo Δt = 0,1 s. Calcula la posición y la velocidad lineal del extremo en t = 0,2 s. Modelo dinámico: [Γ; F] = [[m₁l₂² + m₂d², 0], [0, m₂]] · [θ̈; d̈] + [2 d m₂ θ̇ ḋ; −d m₂ θ̇²]. Datos: m₁ = m₂ = 1 kg, l₂ = l₃ = 1 m, θ(0) = 0 rad, d(0) = 0,25 m.

Antes de empezar: primero se obtienen las aceleraciones, luego se integran en el tiempo y al final se aplica la cinemática y la Jacobiana.
Paso 1 · Despejar las aceleraciones

θ̈ = (Γ − 2 d m₂ θ̇ ḋ) / (m₁l₂² + m₂d²). Con los datos: θ̈ = (Γ − 2dθ̇ḋ) / (1 + d²).

d̈ = (F + d m₂ θ̇²) / m₂. Con los datos: d̈ = F + d θ̇².

Paso 2 · Método de integración

Se usa Euler con Δt = 0,1 s: q̇ₖ = q̈ₖ₋₁·Δt + q̇ₖ₋₁ y qₖ = q̇ₖ₋₁·Δt + qₖ₋₁. Es el mismo método de la solución de referencia.

Paso 3 · Condiciones iniciales (t = 0)

θ̇ = ḋ = 0, θ = 0 rad, d = 0,25 m. Entonces θ̈₀ = 20 / 1,0625 = 18,82 rad/s² y d̈₀ = 10 m/s².

Paso 4 · Primer paso (t = 0,1 s)

θ̇₁ = 18,82 · 0,1 = 1,88 rad/s. ḋ₁ = 10 · 0,1 = 1 m/s. θ₁ = 0 rad. d₁ = 0,25 m.

θ̈₁ = (3·0,01 + 0,2 + 20 − 2·0,25·1,88·1) / 1,0625 = 19,29 / 1,0625 = 18,15 rad/s². d̈₁ = 5·0,1 + 10 + 0,25·1,88² = 11,38 m/s² (con 1,8824 rad/s en lugar de 1,88 sale 11,39).

Paso 5 · Segundo paso (t = 0,2 s)

θ̇₂ = 18,15 · 0,1 + 1,88 = 3,70 rad/s. ḋ₂ = 11,38 · 0,1 + 1 = 2,14 m/s. θ₂ = 1,88 · 0,1 = 0,188 rad. d₂ = 1 · 0,1 + 0,25 = 0,35 m.

Paso 6 · Cinemática directa y Jacobiana

x = −(d + l₃) sen θ, y = (d + l₃) cos θ.

J = [[−(d + l₃) cos θ, −sen θ], [−(d + l₃) sen θ, cos θ]].

Paso 7 · Posición del extremo

x = −1,35 · sen(0,188) = −0,252 m. y = 1,35 · cos(0,188) = 1,326 m.

Paso 8 · Velocidad lineal del extremo

ẋ = −1,35 · cos(0,188) · 3,70 − sen(0,188) · 2,14 ≈ −5,30 m/s. ẏ = −1,35 · sen(0,188) · 3,70 + cos(0,188) · 2,14 ≈ 1,17 m/s.

|v| = √(ẋ² + ẏ²) ≈ 5,43 m/s.

Ojo: la solución de referencia redondea a 3,69 rad/s y 2,13 m/s en el paso 5, cuando los valores sin redondear son 3,6978 y 2,1386. Con ese redondeo sale |v| = 5,42 m/s; sin él, 5,43 m/s. La diferencia es pequeña, pero conviene conservar decimales en cada paso. El resultado depende además del método numérico (Euler con Δt = 0,1 s).

# Sistemas Robotizados · Guía de estudio

Guía de estudio de la asignatura Sistemas Robotizados (GIEIA, 3º, curso 2026-27).

- **Web (GitHub Pages):** `index.html` es la portada. Incluye temas, prácticas, exámenes resueltos, autoevaluación, formulario, glosario y plan de estudio, con buscador.
- **Descargas** (`descargas/`): guía completa en un solo HTML, y PDFs de la guía completa y de los ejercicios resueltos (con marcadores).
- **Scripts** (`scripts_practicas/`): funciones de Python para cuaterniones, matrices DH y encadenado de sistemas, con tests (`python -m pytest` o `python test_practicas.py`).

La web funciona sin conexión tras la primera carga (service worker). Para instalarla como app, usa "Añadir a pantalla de inicio".
